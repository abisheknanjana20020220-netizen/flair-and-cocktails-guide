# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-07-14

### Added

- Initial project setup with Next.js 14
- Navbar component with navigation links
- Footer component with social links
- Hero section with animations
- Features showcase section
- Course listing and card components
- Courses page with grid layout
- Cocktails page with recipes
- Flair tricks page with difficulty levels
- Resources page for downloads
- Authentication pages (Login, Signup)
- Contact page with form
- Privacy policy page
- Terms and conditions page
- API routes for courses, cocktails, flair tricks
- API routes for authentication (login, signup)
- API contact route
- Responsive design with Tailwind CSS
- Smooth animations with Framer Motion
- Global styling and theme
- TypeScript configuration
- Docker support

### Components

- Navbar: Navigation with mobile menu
- Footer: Site footer with links and social media
- Hero: Landing page hero section
- Features: Feature showcase cards
- CourseCard: Individual course card
- CoursesGrid: Grid of course cards

### Pages

- Home: Landing page
- /courses: Courses listing
- /cocktails: Cocktail recipes
- /flair: Flair techniques
- /resources: Resources and downloads
- /login: User login
- /signup: User registration
- /contact: Contact form
- /privacy: Privacy policy
- /terms: Terms and conditions

### API Endpoints

- GET /api/courses
- GET /api/courses/[id]
- GET /api/cocktails
- GET /api/flair
- POST /api/auth/login
- POST /api/auth/signup
- POST /api/contact
- GET /api/health

### Styling

- Dark theme with gold accents
- Responsive design
- Smooth transitions and animations
- Custom scrollbar styling
